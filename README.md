# stimulsoftgo

Unofficial, community-maintained Go library for working with Stimulsoft.

This project is not affiliated with, endorsed by, or sponsored by Stimulsoft or CloudReports sp. z o.o.

## Installation

```bash
go get github.com/theerudito/stimulsoft_golang@v0.1.2
```

## Usage

```go
package main

import (
	"fmt"

	stimulsoftgo "github.com/theerudito/stimulsoft_golang"
)

func main() {
	fmt.Println(stimulsoftgo.Hello())
}
```
